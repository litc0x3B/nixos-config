# rc-sync - обёртка для rclone bisync

## Цель
Сделать консольную программу на python для упрощения использования rclone bisync для маппинга разных путей на жёстоком диске на разные пути на удалённом диске. 

В основной функционал программы должны входить
1. Интерактивное задание задание маппингов через команды cli.
2. Автоматическая настройка демона синхронизации и удобная проверка его статуса.
3. Декларативное задание маппингов через файл конфигуарции для дальнейшего использования с home manager в операционной системе nix.

## Концептуальная модель данных
### Конфигурация конкретного маппинга
- Alias
- Path1
- Path2
- ExtraFlags - дополнительные аргументы, которые передаются rclone
- AppendGlobalFlags - добавлять ли аргументы из глобальной конфигурации 
- ForceInitNonEmpty - игнорировать обязательное условие синхронизации (default = false)

### Глобальная конфигурация
- ExtraFlags - дополнительные аргументы, которые передаются rclone. (default= "--resilient --max-lock ${SyncFreqMinutes - 1}m") 
- RclonePath - команда для вызова rclone. (default = "rclone")
- SyncFreqMinutes - Частота синхронизации в минутах. Обязательно >= 3

### Состояние маппинга
- Path1
- Path2
- IsInitialized - был ли проведён resync в первый раз

## Описание функционала

1. Задание файла конфигурации и файла с состоянием переменными окружения
2. Команды
   1. mapping add <alias> <path1> <path2> <extraFlags>
   2. mapping remove <alias>
   3. mapping update <alias> <flags> - для него два варианта <flags>
      1. --all, -a <path1> <path2> <extraFlags>
      2. Набор опциональных флагов: 
         1. --path1, p1 <path1>
         2. --path2, p2 <path2>
         3. --extra-Flags <extraFlags>
   4. mapping list - выводит все маппинги вместе с их конфигурациями
   5. config set <flags> - настройки для глобального конфига с опциональными флагами для каждого поля глобальной конфигурации
   6. sync now (<alias>+|all) <extraFlags>
   7. sync enable (<alias+|all>)
   8. sync disable
   9. sync validate <configPath>
